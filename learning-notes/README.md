# Learning Notes

This folder contains explanatory notes on technical concepts encountered during development.

## How to Use
- Browse by date or search by keyword
- Each note is self-contained and can be read independently
- Notes are written for a PM audience — accessible but not dumbed down

## Categories
- **Code Pattern** — React hooks, async patterns, common idioms
- **Technical Term** — Jargon, concepts, named patterns
- **Architecture** — Design decisions, trade-offs, system structure
- **Syntax** — Language features, operators, type annotations
- **Tool/Library** — Framework-specific features, APIs, configurations

## Creating Notes

Use `/learning-opportunity` when you have code or text selected that you'd like explained. A detailed note will be saved here automatically.
